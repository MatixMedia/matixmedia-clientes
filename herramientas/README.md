# Herramientas del sistema MatixMedia

Scripts que usan los skills `mm_` de Claude. No contienen credenciales.

| Archivo | Para qué | Lo usa |
|---|---|---|
| `mm_github.py` | Subir, leer, listar y borrar archivos en GitHub por la API cuando la sesión no tiene `git` | mm_subir y los skills que publican o usan la Bandeja |
| `hub_tool.py` | Leer y editar los datos del Hub de Contenido (`contenido_hub.html`) | mm_hub |

Descarga directa:

```
https://raw.githubusercontent.com/MatixMedia/matixmedia-clientes/main/herramientas/mm_github.py
https://raw.githubusercontent.com/MatixMedia/matixmedia-clientes/main/herramientas/hub_tool.py
```
